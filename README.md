This project implements MobileNetV4 with Post-Training Quantization (PTQ) for efficient classification of Indian heritage sites using the IHDS dataset. By compressing the model from 33.99 MB to as low as 4.05 MB with minimal accuracy loss (95.84% → 88.62%), it outperforms MobileNetV3 and demonstrates an ideal balance between accuracy and compactness for edge device deployment. The approach highlights MobileNetV4’s potential for cultural heritage preservation, as well as broader applications in real-time image classification for mobile, IoT, and healthcare domains.
